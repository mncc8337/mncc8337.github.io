# mncc8337.github.io
my stupid webpage, now made using my own static site generator
## file metadata
- `title`: page title, required, type `String`
- `description`: page description, optional, type `String`, default ""
- `creation_date`: creation date, required, type `String`
- `show_creation_date`, do show creation date on page description, optional, type `String`, default `True`
- `article`, an article or not, optional, type `Bool`, default `True`
- `is_directory_index`: flag to generate file index as page content, optional, type `Bool`, default `False`
- `skip_md`: skip markdown parser, use raw file content as page content, optional, type `Bool`, default `False`
- `skip_header`: skip header generator, optional, type `Bool`, default `False`
modified dates are generated upon commiting
